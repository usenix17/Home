## Phase 3 -- packaging (KEY FINDINGS)
- **Stock `quarterly` pkg has NO `freeipa-server`** -- the port was added
  2026-08-18 and is only on the `latest` branch this quarter (FreshPorts:
  "will be in the next quarterly branch"). NOT broken.
- **Fix: point the jail's pkg repo at `latest`.** Wrote
  `/usr/local/etc/pkg/repos/FreeBSD-ports.conf` overriding `FreeBSD-ports` to
  `pkg+https://pkg.FreeBSD.org/${ABI}/latest` (mirror_type SRV, FINGERPRINTS).
  `freeipa-server-4.13.2_1` then installs as a binary package. No source build
  of freeipa-server itself needed.
- MIT `krb5-1.22.2_3` pulled in as a dependency. `ipa-replica-install` present
  (**Task 3.3 feasibility gate PASSED**).
- **Remaining GSSAPI_MIT problem (as the spec predicted):** the binary
  `cyrus-sasl2-gssapi` / `py-gssapi` are built `GSSAPI_BASE`. Current SASL
  plugin links base krb5:
  `ldd /usr/local/lib/sasl2/libgssapiv2.so -> /usr/lib/libgssapi_krb5.so.122`
  (WRONG). Per the maintainer README this makes `ipa-*-install` fail at the end
  with "Cannot find KDC". Must rebuild `security/cyrus-sasl2-gssapi` and
  `security/py-gssapi` with `GSSAPI_MIT` so they link `/usr/local/lib/...`.
  Runtime consumers need no rebuild (dlopen).
