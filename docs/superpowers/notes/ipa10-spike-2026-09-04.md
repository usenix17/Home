## HANDOFF -- operator runs these (needs admin pw; writes to production ipa9)
Set the admin password locally first: `read -rs ADMIN_PW`

Phase 0 (safety, on ipa9):
```
ssh cloud@ipa9.starnix.net "echo '$ADMIN_PW' | kinit admin && \
  sudo ipa server-find && sudo ipa-replica-manage list && \
  sudo ipa-replica-manage list-ruv && sudo ipa-backup"
```
Phase 5 (enroll + CA-less replica, in the jail):
```
ssh cloud@beastyboi.starnix.net "sudo bastille cmd ipa10 ipa-client-install -U \
  --server=ipa9.starnix.net --domain=starnix.net --realm=STARNIX.NET \
  --principal=admin --password='$ADMIN_PW' --no-ntp --force-join"
ssh cloud@beastyboi.starnix.net "sudo bastille cmd ipa10 ipa-replica-install -U \
  --principal=admin --admin-password='$ADMIN_PW' --no-ntp"
ssh cloud@beastyboi.starnix.net "sudo bastille cmd ipa10 sh -c \
  'sysrc freeipa_server_enable=YES dbus_enable=YES gssproxy_enable=YES; ipactl status'"
```
If either install fails partway, run the Phase 8 rollback before retrying.

## Phase 5 attempt 1 -- FAILED (jail-side, production untouched)
- `ipa-client-install` died with:
  `FileNotFoundError: [Errno 2] No such file or directory:
  '/usr/local/etc/krb5.conf.d/freeipa'` (client.py configure_krb5_snippet ->
  shutil.copy to paths.KRB5_FREEIPA_DEFAULTS).
- **Root cause: FreeBSD-port bug** -- the port does not create
  `/usr/local/etc/krb5.conf.d/`, so the krb5 include snippet copy fails. This is
  local config, BEFORE any server enrolment -- `/etc/ipa` and
  `/etc/sssd/sssd.conf` were absent, so **ipa9 was NOT modified** (no rollback
  needed).
- Also: `sudo` was not installed in the jail (installer warns, non-fatal).
- **Fix applied (jail prep):** `mkdir -p /usr/local/etc/krb5.conf.d`
  (mode 755) and `pkg install -y sudo`. For codification, the role must create
  this dir before running ipa-client-install.
- Re-run the Phase 5 client-install fresh (no --uninstall needed).
